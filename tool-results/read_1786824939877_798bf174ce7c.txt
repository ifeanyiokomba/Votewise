    30→## API Contract Reference (for frontend agents)
    31→
    32→All routes return `{ success: true, data }` or `{ success: false, error: { message, code, details? } }`. Client helper: `apiFetch<T>(url, init)` from `@/lib/api-fetch`.
    33→
    34→Auth:
    35→- `POST /api/auth/register` body `{name,email,password,organizationName}` → `{user,organization}`. Sets session cookie.
    36→- `POST /api/auth/login` `{email,password}` → `{user}`.
    37→- `POST /api/auth/logout`.
    38→- `GET /api/auth/me` → `{user, organization}` or `{user:null}`.
    39→- `POST /api/auth/forgot-password` `{email}` → `{requested:true}`.
    40→- `POST /api/auth/reset-password` `{token,password,confirmPassword}` → `{reset:true}`.
    41→
    42→Elections (org admin only):
    43→- `GET /api/elections` → `{elections:[{...,_count:{voters,positions,candidates}}]}`.
    44→- `POST /api/elections` `{name,description?,type,startTime?,endTime?,timezone?}` → `{election}` (or `{limitExceeded:true,message}` if plan full).
    45→- `GET/PATCH /api/elections/[id]`.
    46→- `POST /api/elections/[id]/status` `{status}` → `{election}` (or `{activationRequired:true,message}` when going LIVE unpaid).
    47→- `GET/POST /api/elections/[id]/positions` `{title,description?,maxChoices?,order?}`.
    48→- `PATCH/DELETE /api/elections/[id]/positions/[positionId]`.
    49→- `GET/POST /api/elections/[id]/candidates` `{name,photo?,bio?,manifesto?,positionId}`.
    50→- `PATCH/DELETE /api/elections/[id]/candidates/[candidateId]`.
    51→- `GET /api/elections/[id]/voters?search=` → `{voters}`. `POST` `{id,eligible}` toggle.
    52→- `POST /api/elections/[id]/voters/import` multipart `file` + `mode`(preview|import) → preview stats or import summary.
    53→- `GET /api/elections/[id]/results` → `{results,visible}` (full ElectionResults object).
    54→- `POST /api/elections/[id]/results/publish` → `{election}`.
    55→- `GET /api/elections/[id]/analytics` → `{stats,timeline,results}`.
    56→- `GET /api/elections/[id]/audit` → `{logs}`.
    57→- `GET /api/elections/[id]/activation` → `{activation}`. `POST .../activation/pay` → `{payment}`. `POST .../activation/negotiate` `{contactName,contactEmail,contactPhone?,message?,proposedAmount?}`.
    58→
    59→Voter (public, no session):
    60→- `POST /api/voter/verify` `{electionId, voterId, channel?, code?}`:
    61→  - if no code → sends OTP, returns `{sent, attemptsRemaining, voterId, channel, devCode}` (devCode only in non-prod, show it in a dev hint box).
    62→  - if code → `{verified, error?, voterId}`.
    63→  - returns `{alreadyVoted:true}` if already voted.
    64→- `POST /api/voter/vote` `{voterId,electionId}` → `{session, ballot:{electionName,positions:[{id,title,description,maxChoices,candidates:[{id,name,photo,bio,manifesto}]}]}}` or `{alreadyVoted:true}`.
    65→- `POST /api/voter/vote/cast` `{voterId,electionId,sessionId,votes:[{positionId,candidateId}]}` → `{receipt,count}`.
    66→- `POST /api/voter/ballot-status` `{voterId,electionId}` → `{hasVoted}`.
    67→- `POST /api/voter/receipt` `{reference}` → `{verified,reference,timestamp}`.
    68→
    69→Public:
    70→- `GET /api/public/results/[id]` → if published `{published:true, election, results}`, else `{published:false,status,electionName,electionId}`.
    71→- `POST /api/public/verify-ballot` `{reference}` → `{verified,reference,timestamp}`.
    72→
    73→Admin (org admin):
    74→- `GET /api/admin/stats` → `{stats,orgStats,recentEvents,recentAudit,elections}`.
    75→- `GET /api/admin/security` → `{events}`. `PATCH` `{id}` resolve.
    76→- `GET /api/admin/users` → `{users}`. `PATCH /api/admin/users/[id]` `{role?,isActive?}`.
    77→- `GET /api/admin/subscription` → `{subscription}`. `POST .../upgrade {tier}`. `POST .../cancel`.
    78→
    79→Platform admin:
    80→- `GET /api/admin/negotiations` → `{negotiations}`. `PATCH /api/admin/negotiations/[id]` `{status,negotiatedAmount?,internalNotes?,assignedToId?}`.
    81→
    82→Support (org member):
    83→- `GET/POST /api/support` `{subject,description,priority}`.
    84→- `GET/PATCH /api/support/[id]` (PATCH `{status?,assignedToId?}`).
    85→- `GET/POST /api/support/[id]/messages` `{body,isInternal?}`.
    86→
    87→Notifications:
    88→- `GET /api/notifications` → `{notifications}`. `POST /api/notifications/[id]/read`.
